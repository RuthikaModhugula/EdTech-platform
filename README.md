📚 EdTech Adaptive Learning Platform

An AI-powered adaptive learning platform that personalizes the learning experience using recommendation systems, sentiment analysis, and AI-based assessments. Built using FastAPI and Streamlit, the platform provides personalized learning recommendations, adaptive quizzes, feedback analysis, and an AI chatbot tutor powered by Gemini AI to enhance student engagement and learning support.

🚀 Features

* Personalized learning recommendations
* Adaptive assessment generation
* Feedback sentiment analysis
* AI chatbot tutor
* FastAPI backend integration
* Interactive Streamlit frontend

🛠️ Technologies Used

* Python
* FastAPI
* Streamlit
* Scikit-learn
* Hugging Face Transformers
* Gemini AI API
* Pandas
* NLP & Recommendation Systems

▶️ How to Run

Create Virtual Environment
python -m venv venv

Activate Virtual Environment
venv\Scripts\activate

Install Requirements
pip install -r requirements.txt

Run Backend API
uvicorn api:app --reload

### Run Streamlit Frontend

```bash
streamlit run str.py
```
